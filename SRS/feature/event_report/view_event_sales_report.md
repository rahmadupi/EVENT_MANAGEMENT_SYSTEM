# View Event Sales Report

### User Story

As an Event Organizer, I can view the event sales report so that I can monitor ticket sales
performance.

### Acceptance Criteria

• The report displays the number of tickets sold per ticket category.
• The report displays the number of bookings with the statuses PendingPayment,
Paid, Expired, and Refunded.
• The report displays the total revenue from paid bookings.

### Details

### Note
The event sales report is generated based on the booking data for a specific event. It provides insights into the sales performance of the event, allowing the Event Organizer to track how many tickets have been sold in each category, the distribution of booking statuses, and the total revenue generated from paid bookings.
