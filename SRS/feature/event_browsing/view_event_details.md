# View Event Details

### User Story

As a Customer, I can view event details so that I can understand the event information and
available ticket options.

### Acceptance Criteria

• The event detail page displays the event name, description, date, location,
organizer, and list of ticket categories.
• Only active ticket categories are displayed for purchase.
• Ticket categories whose sales period has not started are displayed with the status
Coming Soon.
• Ticket categories whose sales period has ended are displayed with the status Sales
Closed.
• Ticket categories with no remaining quota are displayed with the status Sold Out.

### Details

### Note

When a Customer views the event details, the system retrieves and displays comprehensive information about the event, including its name, description, date, location, and organizer. The system also presents a list of ticket categories available for purchase, but only those that are currently active. For ticket categories that are not yet available for sale, the system indicates their status as Coming Soon. For those that have passed their sales period, the status is shown as Sales Closed. Additionally, if a ticket category has no remaining quota, it is marked as Sold Out. This allows Customers to easily understand the availability of tickets and make informed decisions about their purchases.
